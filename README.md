# X-Saturn Toolkit v1.0 🚀

CLI Toolkit berbasis Python untuk Termux yang mengintegrasikan fitur Magic Link Alight Motion Premium API dan berbagai utilitas lainnya.

---

## 🛠️ Fitur Utama

- **Magic Link Alight Motion V1**: Kirim email verifikasi dan proses pengaktifan akun premium.
- **Magic Link Alight Motion V2**: Bulk Generator akun premium otomatis.
- **Support Termux**: Tampilan antarmuka CLI yang ringan dan responsif.

---

## 📥 Panduan Instalasi di Termux

Jalankan perintah berikut secara berurutan pada aplikasi Termux Anda:

```bash
pkg update && pkg upgrade -y
pkg install python git -y
git clone [https://github.com/USERNAME_KAMU/X-saturn.git](https://github.com/USERNAME_KAMU/X-saturn.git)
cd X-saturn
pip install -r requirements.txt
python main.py
